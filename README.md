# Wonder Box 奇趣宝盒

Wonder Box 是一个基于 Python 和 Pygame 的互动游戏宝盒，汇集图鉴、问答、双人游戏、占卜、诗词和宠物养成等八项功能。可以在电脑上模拟操作，也可以连接树莓派的屏幕和实体按键使用。

## 启动与操作

在装有 Python 和 Pygame 的环境中，从项目根目录启动：

```bash
python main.py
```

总界面使用 K1/K2 选择游戏，短按 K3 进入。游戏页面若 K1、K2、K3 都没有短按返回功能，长按 K3（约 1 秒）可返回上一级或退出；已有短按返回时，以屏幕提示为准。长按只触发一次，进入下一步操作前需松开再按。本机可用数字键 1/2/3 或鼠标操作。

每次启动总界面都会显示使用声明，短按 K3 或点击“知道了”确认后进入，长按 K3 则不确认并退出。从游戏返回时不会重复显示。

本机默认竖屏，运行以下命令可预览横屏；按 Esc 关闭模拟窗口：

```bash
python main.py --sim --landscape
```

总界面长按 K3 打开关机确认。默认选中取消；使用 K1/K2 选择，按 K3 确认。树莓派确认关机后，程序先将 SPI 屏幕刷为全黑，再请求系统关机。模拟模式不会关闭电脑。

### 音频与杂音说明

音效由 `common/audio.py` 统一管理，按运行环境自动选择输出：电脑模拟用系统声卡，树莓派用 ALSA（匹配 I2S 功放）。需要发声的游戏必须在实际初始化显示之前调用 `common.audio.prepare()` 声明，随后把 `GameAudio` 用于播放。

为避免 MAX98357 等功放在音频设备开关时发出"啪啪"的爆音，采取了三点措施：不需要声音的程序（含总界面）强制使用 dummy 音频驱动（无条件覆盖环境变量，即使 shell 里残留了 `SDL_AUDIODRIVER=alsa` 也不会打开真实设备），因此进出游戏、返回总界面时不会再有爆音；需要发声的游戏声明后，`pygame.init()` 阶段一次打开真实设备并复用，不重复 `quit/init`；音效和背景乐带淡入，退出时先把音量归零、淡出再停播，降低设备关闭瞬间的爆音。如需强制静音，设环境变量 `POKEMON_NO_AUDIO=1`。

## 十项功能

### 1. 宝可梦图鉴

浏览第 1 至第 4 世代共 493 只宝可梦，查看图片和资料。可以按世代及已发现、未发现状态筛选，调整显示顺序和界面风格；查看过的宝可梦会自动记为已发现，发现记录和设置会保存。

### 2. 头脑挑战

两位玩家轮流回答同一组 10 道题，每题限时 30 秒，内容包括常识、文字和逻辑等。答对更多题的玩家获胜；答对数相同时比较答题总用时。答题时 K1/K2/K3 分别选择三个答案。

### 3. 脑筋急转弯

浏览趣味问答，可选择全部题目、未答过或已答过的题目。答题时 K1 回看上一题，K2 切换下一题，K3 显示答案；看过答案的题目会记录为已答过，也可以在菜单中重置进度。详见[脑筋急转弯说明](Riddles/README.md)。

### 4. 骰子对决

两位玩家分别用 K1 和 K2 控制骰子，比拼点数。点数较小的一方接受转盘选出的趣味挑战，内容包括动作、表情和小问答等；点数相同时重新开始一轮。挑战转盘短按 K2 返回骰子页，骰子页长按 K3 返回总界面。

### 5. 幸运转盘

和朋友一起转出小游戏，主题包括节奏、动作、故事、寻找、想象和友爱。按 K3 启动或停止转盘，停下后显示对应的活动；按 K1 可以换一道同主题活动。

### 6. 星愿占卜屋

提供今日运势、星座查询和情感预测三种模式。可以抽牌查看今日或情感提示，也可以浏览星座的性格、感情、事业等小档案。结果仅供娱乐。

### 7. 诗词大赛

选择经典名篇、唐诗、宋词、混合题库或儿童诗词，每场回答 10 道题，包括诗句接龙、辨认作者和辨认诗题或词牌。K1/K2/K3 分别选择答案。玩法和题库来源见[诗词大赛说明](Poetry%20Quest/README.md)。

### 8. 宠物乐园

多位主人可以各自领养一只伙伴，通过喂食、玩耍、洗澡、睡觉、摸摸和外出等计时互动陪伴成长，还可以完成每日任务、解锁技能和兑换饰品。

宠物进度自动保存，离线状态变化单次最多按 12 小时补算，离线期间到期的动作也会结算。玩法和存档说明见[宠物乐园说明](Virtual%20Pet/README.md)。

### 9. 狼人杀

离线主持助手，支持 4–12 人自定义配板，默认选择 6 人；其中 4 人推荐 1 狼 1 预言家 2 村民、5 人推荐 1 狼 1 预言家 3 村民。可在“推荐配板”中增减人数并预览对应配置，确认应用后还可逐项调整角色数量、身份显示时长（默认 2 秒，可设为 1–10 秒）和“首夜平安夜”开关；调整任一特殊角色数量时，村民数量会自动反向配平，保持总人数不变。“首夜平安夜”默认开启：首夜守卫无需守护、狼人只睁眼确认同伴而不夜袭、女巫不使用解药和毒药，天亮直接进入白天讨论；在编辑界面按 K1/K2 可将其关闭。选中“确认开局”后，玩家从 1 号起依次短按 K3 抽取身份；身份到时自动隐藏，不会重复抽牌。全部发完后交回主持人，按提示推进夜间行动、白天讨论和投票。

游戏进行中长按 K3 会打开「本局将中断」确认页；按 K1 继续当前局，按 K3 确认后回到角色配置。角色数量会保留，当前对局进度作废。在角色配置主界面长按 K3 可直接返回总界面。窗口关闭按钮或 Esc 仍可直接退出程序。

夜间提示区分可照念的台词和主持人操作，并明确提示各身份要指定的行动目标。狼人睁眼时开始 10 秒倒计时，仅供狼人达成共识；计时结束后仍由主持人进入登记页选择狼袭目标或明确选择空刀，主持人登记和确认不计时。所有存活玩家（包括狼人）都可作为狼袭目标。守卫、预言家和女巫也可在各自行动页按 K3 标记目标或用药；确认后自动推进到下一步骤。夜间行动和记录期间可用 K1/K2 在身份名单与本轮夜间记录间直接切换；记录按轮保存。预言家查验时只向他比拇指（向上为好人、向下为狼人）；女巫拇指向上表示救人，指出玩家表示用毒，摇头表示不用。解药和毒药各限整局一次，每晚最多用一瓶；女巫首夜可以自救，之后不能自救。为防用药情况被玩家从流程中推断，只要女巫存活，每晚都会依次完整播报“是否用解药”和“是否用毒药”两句并各自走完登记过场，即使对应药已用完也照常念台词、按“不用药”继续；是否用药只显示在“仅主持人看”的页面里，不会通过环节有无或台词增减暴露。狼袭目标即使被守护，仍可被女巫选作解药或毒药目标；解药救狼袭，毒药不受守护影响。守卫不能守自己，可以守护其他任何存活玩家，包括连续守同一人；“不守护”表示跳过行动，守护不挡毒。

天亮时，面板自动根据狼袭、守护、解药和毒药标记出局玩家，并显示狼袭或毒杀原因及玩家行动标记；主持人不用重新选择死亡者，只需确认结果。狼袭被守护或解药抵消时不会出局，毒杀不受守护影响。无人出局时，对玩家只宣布「昨夜平安」，不透露是否有人遭袭或被救。结束结算页按 K1 进入逐轮复盘，可查看当轮守护、狼袭、查验、用药和每位玩家的身份及存活/出局状态。

夜间阵亡和白天放逐的登记页显示全部玩家的号码、身份和状态，仅供主持人查看；已出局者不可再选。用 K1/K2 移动、K3 勾选或取消，也可直接点击玩家，再选“确认登记”提交；白天放逐确认后由被放逐玩家发表遗言，再进入下一夜或胜负结算；无人出局时直接确认。狼人全部出局时好人胜；存活狼人数不少于存活好人数时狼人胜。

身份名单和胜负结算都会列出所有玩家的角色和存活状态。出局玩家会显示轮数及登记方式（夜间阵亡或投票放逐）。

### 10. 粘猴

按住 K1 蓄力伸长木棍，松开后让木棍搭向下一块平台；长度合适时猴子会自动过桥并继续闯关。进入后按 K1 开始，K3 返回。

## 树莓派配置

树莓派需要项目已有的 Pygame、RPi.GPIO、中文字体和 `/dev/fb1` 配置，按键使用 GPIO 5、23、24（K1 由 GPIO18 改为 GPIO5，避免与 I2S 音频 BCLK 冲突；对应物理引脚 29）。关机需要以 root 运行，或允许当前用户非交互执行 `sudo -n shutdown -h now`；权限不足时会显示关机失败。
